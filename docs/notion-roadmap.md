# GrowdoAds MVP 개발 로드맵 v2

> 기준일: 2026-08-09  
> 기준: 1인 풀타임 개발, Google Ads 우선 연동, PostgreSQL + TypeORM  
> 목표: 가입부터 캠페인 작성·승인·게시·성과 확인·결제까지 하나의 흐름으로 완성  
> 일정 성격: 플랫폼 심사와 외부 API 권한에 따라 조정되는 개발 기준안

## 1. MVP 완료 기준

사용자가 개인 워크스페이스를 생성하고 광고계정을 연결한 뒤, 공통 캠페인을 작성하여 플랫폼 변환 결과를 확인·승인하고 게시할 수 있어야 한다. 게시 실패는 광고계정과 단계별로 확인·재시도할 수 있고, 집행 성과와 SaaS 구독료는 분리하여 조회할 수 있어야 한다.

### MVP 핵심 사용자 흐름

1. 회원가입·로그인 및 개인 워크스페이스 생성
2. 사업정보·광고 목표 입력
3. 플랜 선택 및 사용 가능 한도 확인
4. Google Ads 연결 및 광고계정 선택
5. 캠페인 초안 생성
6. 예산·입찰·타기팅·소재 설정
7. Google Ads 입력값 변환 및 검증
8. 집행 결과 미리보기 및 사용자 승인
9. 플랫폼 게시와 부분 실패·재시도
10. 캠페인 수정·중단·재개
11. 광고비와 성과 확인
12. AI 분석·추천 및 리포트 확인
13. SaaS 구독 결제·해지·환불 처리

### 출시 구분

| 구분 | 포함 범위 | 목표 시점 |
|---|---|---|
| Core Beta | 워크스페이스, 플랜 제한, Google 연결, 캠페인 작성·게시·운영 | 2026-12-18 |
| Paid MVP | 성과, AI·리포트, 실제 결제, 운영 안정화 포함 | 2027-02-19 |
| 확장 버전 | Meta·네이버 게시 어댑터 및 멀티 플랫폼 고도화 | Paid MVP 이후 |

- [ ] 플랫폼별 API 권한 및 심사 일정 확인

- [ ] Access Token 갱신과 전체 세션 종료 검증
- [ ] 내 워크스페이스 목록 조회 API
- [ ] 현재 워크스페이스 조회·수정 API

- [ ] 성공한 외부 자원 중복 생성 방지
- [ ] 광고계정별 성공·실패를 합산한 partial 상태 처리
- [ ] 실패 지점부터 수동 재시도 API
- [ ] 호출 제한·일시 장애의 자동 재시도 정책
- [ ] 게시 전체 흐름 통합 테스트

**완료 기준**  
사용자가 승인한 스냅샷과 동일한 내용만 게시되고, 일부 단계가 실패해도 성공한 작업은 보존되며 실패 지점부터 재시도할 수 있다.
