## 2. 우선순위별 요약

| 우선순위 | 의미 | 출시 판단 |
|---|---|---|
| P0 | 핵심 사용자 흐름 또는 데이터 신뢰성에 필수 | 하나라도 빠지면 MVP 배포 불가 |

## 19. 기능 완료의 공통 정의

모든 기능은 다음 조건을 충족해야 `완료`로 변경한다.

- [ ] 기획 정책과 예외 상황이 확정됨
- [ ] 프론트엔드와 백엔드가 실제 데이터로 연결됨
- [ ] 정상·빈 데이터·권한 없음·실패 상태가 처리됨
- [ ] 권한과 사용자 데이터 격리가 검증됨
- [ ] 주요 계산값과 원본 데이터가 비교 검증됨
- [ ] 필요한 자동 테스트가 추가됨
- [ ] 운영에서 오류 원인을 추적할 로그가 존재함
- [ ] 완료 조건을 기획자 또는 담당자가 직접 확인함
