# GrowdoAds MVP 기능 범위

> 협의용 초안  
> 기준: 구독형 광고 운영 SaaS, Google·Meta·네이버 공통 캠페인 모델, 매체별 연동 순차 검증

## 1. MVP 목적

광고대행사를 이용하기 부담스러운 셀프서브 광고주가 광고계정을 간편하게 연결하고, 여러 매체의 캠페인을 한곳에서 작성·게시·운영하며, 핵심 성과와 데이터에 근거한 AI 설명 및 다음 행동을 확인할 수 있는 구독형 서비스를 제공한다.

MVP에서는 사용자의 명시적 승인 없이 광고를 변경하지 않는다. 캠페인 게시·수정 작업은 항상 변경 내용과 예상 대상을 먼저 보여주고 사용자가 승인한 후 실행한다.

## 2. 주요 사용자

- 광고를 직접 운영하지만 매체별 지표와 마케팅 용어가 어려운 광고주
- 성과 변화의 원인과 다음에 해야 할 행동을 판단하기 어려운 광고주
- 광고대행사 비용 또는 운영 방식에 부담을 느끼는 소규모 사업자와 마케터

## 3. 핵심 사용자 흐름

1. 회원가입 및 로그인
2. 사업·상품 정보와 광고 목표 설정
3. 구독 플랜 선택 및 결제
4. 광고계정 연결 또는 성과 파일 업로드
5. 공통 캠페인 초안 작성 및 매체별 게시 승인
6. 광고 성과 데이터 수집
7. 통합 대시보드에서 핵심 성과 확인
8. AI가 제공하는 성과 요약·원인 후보·추천 행동 확인
9. 캠페인 수정·중단·재개 또는 추천 행동 기록
10. 주간 성과 리포트 수신

## 4. MVP 포함 기능

### 4.1 회원·로그인 및 기본 설정

- 이메일 회원가입 및 로그인
- 소셜 로그인
- 로그인 상태 유지, 토큰 갱신 및 로그아웃
- 비밀번호 재설정 및 회원 탈퇴
- 프로필과 기본 사업정보 입력·수정
- 상품·서비스 및 주요 타깃 고객 정보 입력
- 광고 목표와 목표 KPI 설정
- 최초 설정 완료 여부에 따른 온보딩 처리

### 4.2 구독 플랜·결제

- 구독 플랜 조회 및 선택
- 신규 구독 결제와 구독 상태 확인
- 플랜 변경, 구독 해지 및 재구독
- 결제 실패 안내와 재결제
- 환불 요청, 환불 가능 금액 확인 및 처리 상태 조회
- 결제·환불 영수증과 이용 내역 확인
- 플랜별 사용자 수·광고계정 수·AI 사용량 제한
- 사용량 조회와 한도 도달 전 알림
- 한도 초과 시 추가 생성·연결·AI 요청 제한
- 광고 플랫폼에 지출한 광고비와 GrowdoAds 구독료를 명확히 구분

### 4.3 광고 데이터 연결

- Google Ads·Meta Ads·네이버 광고 계정 연결 및 연결 해제
- 연결할 광고계정 선택
- 연결 상태, 재인증 필요 여부 및 마지막 수집 시각 표시
- API 연동이 어려운 데이터를 위한 CSV 업로드
- 업로드 컬럼 매핑, 데이터 미리보기 및 오류 안내
- 중복 파일 또는 데이터의 중복 반영 방지

> 세 매체를 공통 구조로 지원하되, 실제 API 연결과 게시 기능은 매체별 검증을 거쳐 순차적으로 활성화할 수 있다.

### 4.4 광고 데이터 수집·관리

- 광고계정과 캠페인 정보 수집
- 비용, 노출, 클릭, 전환, 매출 등 일별 성과 수집
- 최초 연결 시 일정 기간의 과거 데이터 수집
- 하루 1회 자동 수집 및 필요 시 수동 갱신
- 수집 실패 기록, 자동 재시도 및 중복 수집 방지
- 매체별 데이터를 공통 지표로 정규화
- CTR, CVR, CPA, ROAS 등 계산 지표 산출
- 통화와 시간대 기준 통일

### 4.5 통합 성과 대시보드

- 비용, 노출, 클릭, CTR, 전환, CPA, ROAS 요약
- 이전 기간 대비 지표 증감 표시
- 일별 성과 추이 차트
- 캠페인별 성과 목록
- 기간·광고계정·캠페인 필터
- 캠페인 검색 및 주요 지표 정렬
- 데이터 수집 중·데이터 없음·수집 실패 상태 표시
- 데이터 출처와 마지막 갱신 시각 표시
- 광고비와 SaaS 구독료를 서로 다른 비용 항목으로 표시

### 4.6 캠페인 작성·게시·운영

- Google Ads·Meta Ads·네이버 광고를 포괄하는 공통 캠페인 초안 모델
- 캠페인명, 목표, 기간, 일·총예산 입력
- 입찰 방식과 목표 입찰값 설정
- 지역·연령·성별·관심사 등 타기팅 설정
- 광고 제목·문구·이미지·영상·랜딩 URL 등 소재 설정
- 매체별 필수 입력값과 허용 범위 검증
- 공통 입력값을 각 광고 플랫폼의 형식으로 변환
- 플랫폼별 지원하지 않는 옵션과 대체값 안내
- 게시 전 최종 입력값, 예상 게시 대상 및 변경 내용 미리보기
- 사용자 명시적 승인 후 플랫폼 게시 작업 실행
- 여러 플랫폼 게시 중 전체·부분 성공과 실패 결과 표시
- 실패한 플랫폼 또는 항목만 안전하게 재시도
- 게시된 캠페인의 수정·중단·재개
- 수정 전후 값과 작업 수행자·시각·결과 기록
- 서비스 상태와 광고 플랫폼 실제 상태의 동기화

### 4.7 AI 성과 분석

- 주요 성과를 쉬운 문장으로 요약
- 눈에 띄는 지표 변화와 이상징후 탐지
- 성과 변화의 가능한 원인 설명
- 유지·중단·확대·추가 검토 등 다음 행동 제안
- 모든 설명과 제안에 판단 근거가 된 수치와 기간 표시
- 데이터가 부족한 경우 분석의 한계와 주의사항 표시
- 사업·상품·광고 목표를 반영한 설명 제공

AI는 ROAS·CPA와 같이 계산 가능한 지표를 직접 생성하지 않고, 서비스에서 검증한 계산 결과만 사용한다. 데이터에 없는 수치를 만들거나 원인을 사실처럼 단정하지 않는다. AI가 캠페인 변경안을 작성할 수는 있지만 실제 반영은 미리보기와 사용자 승인을 거쳐야 한다.

### 4.8 추천 행동 및 리포트

- AI가 제안한 행동 목록 저장
- 추천 행동을 실행·보류·완료 상태로 관리
- 추천 행동에 사용자 메모 기록
- 주간 핵심 성과 리포트 생성
- 주요 변화, 이상징후 및 해야 할 일 요약
- 대시보드 내 리포트 조회
- 이메일을 통한 주간 리포트 발송
- 발송 실패 재시도 및 발송 이력 관리

### 4.9 최소 관리자·운영 기능

- 사용자와 광고계정 연결 상태 확인
- 데이터 수집 성공·실패 이력 확인
- 실패한 수집 작업 수동 재실행
- AI 분석 결과와 근거 데이터 확인
- 주간 리포트 발송 상태 확인
- 구독·결제·환불 상태 및 플랜별 사용량 확인
- 캠페인 게시·수정 작업과 부분 실패 상태 확인
- 서비스 오류 로그와 주요 작업 상태 모니터링
- 사용자별 광고 데이터 접근 권한 분리

## 5. MVP 제외 기능

다음 기능은 초기 MVP에 포함하지 않고 파일럿 결과에 따라 후속 버전에서 검토한다.

- 사용자 승인 없는 광고 예산·상태·타기팅 자동 변경
- 실시간 입찰 또는 자체 광고 송출 기능
- 복잡한 팀·조직·대행사 권한 관리
- 일간·월간·맞춤형 리포트
- 고급 광고 소재 제작 및 자동 최적화
- 모바일 앱

## 6. MVP 완료 및 검증 기준

### 6.1 제품 개발 완료 기준

MVP 기능 개발은 다음 조건을 모두 충족했을 때 완료된 것으로 판단한다.

1. 사용자가 회원가입 후 사업정보와 광고 목표 설정을 완료할 수 있다.
2. 사용자가 플랜을 선택하고 결제·변경·해지·환불 상태를 확인할 수 있다.
3. 플랜별 사용자·광고계정·AI 사용량 제한이 정확하게 적용된다.
4. 사용자가 광고계정을 연결하거나 성과 파일을 업로드할 수 있다.
5. 사용자가 공통 캠페인 초안을 작성하고 게시 전 결과를 미리 확인할 수 있다.
6. 사용자 승인 후 캠페인이 대상 플랫폼에 게시되며 부분 실패와 재시도가 처리된다.
7. 게시된 캠페인을 수정·중단·재개하고 모든 변경 이력을 확인할 수 있다.
8. 광고계정의 캠페인과 최근 성과 데이터가 자동으로 수집된다.
9. 서비스의 비용·클릭·전환 등 핵심 수치가 광고 매체 원본과 일치한다.
10. 대시보드에서 기간별·캠페인별 핵심 성과와 변화를 확인할 수 있다.
11. AI가 근거 수치와 함께 성과 변화, 원인 후보 및 다음 행동을 제안한다.
12. 데이터가 부족한 경우 AI가 원인을 단정하지 않고 분석의 한계를 표시한다.
13. 사용자가 추천 행동을 기록하고 주간 리포트를 자동으로 받을 수 있다.
14. 광고비와 SaaS 구독료가 결제·대시보드·리포트에서 명확히 구분된다.
15. 운영자가 결제, 게시, 수집, AI 및 리포트 실패를 확인하고 재처리할 수 있다.

### 6.2 파일럿 검증 성공 기준

- 파일럿 고객 5곳 이상이 4주 동안 서비스를 반복 사용한다.
- 참여 고객이 광고계정 연결 또는 파일 업로드를 완료한다.
- 핵심 광고 수치가 원본 매체 데이터와 일치한다.
- AI 분석이 근거와 데이터 부족 여부를 올바르게 표시한다.
- 대시보드, 추천 행동 또는 주간 리포트가 반복적으로 사용된다.

## 7. 개발 전 확정이 필요한 사항

- 세 매체의 실제 연결·게시 기능을 동시에 출시할지 순차 출시할지
- 플랫폼별 MVP에서 지원할 캠페인 유형과 광고 목표
- 공통 캠페인 모델에서 지원하지 않는 플랫폼 고유 옵션 처리 방식
- 캠페인 변경 승인 권한과 게시 실패 시 롤백 정책
- 광고 데이터 최초 수집 기간과 일별 수집 시각
- 전환·매출 데이터의 기준과 광고 매체 수치와의 관계
- 기준 시간대, 통화 및 환율 적용 방식
- CSV 외 XLSX 업로드를 MVP에 포함할지 여부
- AI에 사용할 모델, 월 사용 한도 및 평가 기준
- 플랜 구성, 가격, 사용자·광고계정·AI 사용량 한도
- 플랜 업그레이드·다운그레이드 반영 시점과 일할 계산 정책
- 해지 효력 시점과 환불 가능 조건·금액 계산 방식
- 결제 실패 시 유예 기간과 서비스 제한 정책
- 광고비 결제 주체와 SaaS 구독료 결제 주체의 구분
- 주간 리포트 발송 요일·시간과 수신 대상
- 고객 데이터와 광고계정 토큰의 보관·삭제 정책
- 무료 파일럿 이후 결제 도입 시점

## 8. 권장 구현 순서

1. 제품 범위와 지표 정의 확정
2. 인증 안정화 및 사업정보 온보딩
3. 구독 플랜·결제·사용량 제한
4. 공통 광고 데이터 모델과 파일 업로드
5. 광고계정 연결 및 자동 데이터 수집
6. 실제 데이터를 사용한 통합 대시보드
7. 공통 캠페인 모델과 캠페인 작성 화면
8. 플랫폼별 변환·검증·게시·부분 실패 처리
9. 캠페인 수정·중단·재개 및 감사 이력
10. 근거 기반 AI 분석과 행동 제안
11. 추천 행동 관리와 주간 리포트
12. 관리자 기능과 운영 안정화
13. 파일럿 고객 검증
